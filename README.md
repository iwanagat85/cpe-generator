# cpe-generator

The CPE is inferred from the application's product name using an LLM fine-tuned with LoRA.


## Install requirements

```bash
pip install -r requirements.txt
```


## Usage

Execution requires 'cpe.sqlite3' generated by [go-cpe-dictionary](https://github.com/vulsio/go-cpe-dictionary/tree/master). Please place the obtained 'cpe.sqlite3' in the 'datas' folder.

### Create dataset

```bash
python create_dataset.py
```

### Create vectorstore

```bash
python create_vectorstore.py
```

### Train

```bash
python train.py
```

### Generate

```bash
python generate.py
```
